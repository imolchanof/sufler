# Изменения

## 1.2.0

- Выбор начертания текста в отдельном списке.
- Локальные Inter Thin 100, ExtraLight 200 и Light 300 с кириллицей.
- По умолчанию — Inter ExtraLight 200; принудительное полужирное начертание убрано.
- Для Segoe UI доступны Light, Semilight, Regular и SemiBold; для других шрифтов список показывает поддерживаемое обычное начертание.
- Сохранение выбранной толщины и переход со старой версии на тонкий текст с сохранением выступления.
- Проверки конкретных файлов и весов тонких шрифтов.

## 1.1.0

Первый публичный релиз для Windows.

- Прокрутка текста с настройкой скорости, паузой, отсчётом и остановкой в конце.
- Размер шрифта от 5 до 100, шаг 1; ползунок и числовой ввод.
- Пять локальных шрифтов: Inter, Segoe UI, Arial, Georgia, Verdana.
- Четыре темы из Done'r; проверенный контраст текста.
- Полный экран, зеркало, линия чтения, скрытие редактора, режим поверх окон.
- Автосохранение текста и настроек; импорт и экспорт `.txt`.
- Значок и меню в трее, восстановление окна, пауза при сворачивании.
- Настройки по шестерёнке: автозапуск Windows и закрытие в трей.
- Один экземпляр приложения, работа без интернета и установки.
