# Как предложить изменение

Если нашли ошибку, создайте Issue: укажите версию приложения, Windows и шаги повторения.

Для изменений кода:

1. Создайте ветку от `main`.
2. Соберите приложение: `powershell -ExecutionPolicy Bypass -File .\src\build.ps1`.
3. Запустите `src\build\Sufler.exe --self-test` и проверьте `src\build\test-output\result.txt`.
4. Для изменений интерфейса проверьте светлые и тёмные темы, минимальное окно и управление клавиатурой.
5. Откройте Pull Request с описанием поведения и результатов проверки.

Не добавляйте в коммиты личные тексты, `session.xml` и папки результатов проверок. Inter и его лицензия должны оставаться в `src/Fonts`.
